# My Website

A simple one-page personal website built with plain HTML, CSS and JavaScript. No build step.

## Before publishing, edit these in `index.html`
- Replace **Your Name** (page title, top left, footer)
- Replace `your-email@example.com` and the phone number `+910000000000`
- Check the Experience section is correct

## Publish on GitHub Pages
1. Upload `index.html`, `style.css`, `script.js` and `README.md` to a new repository.
2. Go to **Settings -> Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**, and click **Save**.
3. Open `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`
